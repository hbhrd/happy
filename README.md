# 전국 둘레길 백과사전

초등학생(3학년 눈높이)을 위한 한 장짜리 둘레길 학습 페이지입니다. 브라우저에서 `index.html`을 열면 바로 볼 수 있어요.

- 30초 모션 그래픽 영상과 음악 (Web Audio로 직접 만든 소리, 파일 없음)
- 기울어지는 3D 지도: 둘레길 12곳 + 고속도로 휴게소 8곳
- 둘레길 "걸어 보기" 모드와 완주 스탬프, 퀴즈, 낱말 수첩, 수료증
- 경쾌한 배경음악 켜기/끄기

## 구조

| 파일 | 내용 |
|---|---|
| `index.html` | 완성된 페이지 (아래 원본을 합친 결과물) |
| `parts/shell.html` | 화면 구성, 디자인(CSS), 동작 스크립트 |
| `parts/video.js` | 30초 영상과 음악 |
| `parts/bgm.js` | 배경음악 |
| `parts/trails.js` | 둘레길·퀴즈·낱말 자료 |
| `parts/rest.js` | 휴게소 자료 |
| `parts/build.sh` | 원본을 합쳐 `index.html`을 만드는 스크립트 |

원본을 고친 뒤 다시 합치려면:

```bash
bash parts/build.sh
```
